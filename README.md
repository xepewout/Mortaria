# Mortaria

Mortaria is a B2B customer relationship management (CRM) application built with ASP.NET Core 7. It provides a centralized platform for managing customer information, appointments, authentication, and business operations.

The application uses Entity Framework Core with MySQL for data persistence and ASP.NET Core Identity for authentication and account management. Calendar functionality is provided through FullCalendar, while Docker support allows the application to be containerized for deployment.

The project also includes an early integration with the Squarespace API for retrieving customer order information and connecting commerce data with customer accounts.
